# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting ("Security" tab > "Report a vulnerability") on this repository.
You will get a reply as soon as possible; this is a hobby project, so please be patient.

## Scope

- The app asks for sensitive permissions (notification access, install packages). Reports about
  misuse or over-reach of any of them are welcome.
- Releases are signed with one release key. APKs from anywhere other than this repository's
  Releases page are not official.
- The app only talks to Open-Meteo (weather, city search) and the GitHub releases API (update check).

Only the latest release is supported.
